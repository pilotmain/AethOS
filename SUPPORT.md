# Support

AethOS is community-supported software.

- Read [the documentation index](docs/README.md) and
  [troubleshooting guide](docs/TROUBLESHOOTING.md).
- Use GitHub Discussions for usage questions when Discussions are enabled.
- Open a bug report only after searching existing issues and collecting a minimal
  reproduction with sensitive values removed.
- Use [SECURITY.md](SECURITY.md) for vulnerabilities; never disclose them in a
  public issue.

Maintainers do not guarantee response times for community support. Paid or
private support, if offered, is separate from the Apache-2.0 license and does not
change community access to the source.
